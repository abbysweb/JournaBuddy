\subsection{1. Vision \& Core Philosophy}\label{vision-core-philosophy}

JournaBuddy helps authors prepare manuscripts by combining three
analysis layers: - \textbf{Symbolic / rule‑based} -- precise,
explainable checks (Module 1). - \textbf{Statistical NLP} -- continuous,
benchmarkable metrics (Module 4). - \textbf{Semantic / embedding +
knowledge graph} -- meaning and relationships (Modules 2, 4).

The system answers four core questions: \textbar{} Question \textbar{}
Module \textbar{} \textbar----------\textbar--------\textbar{}
\textbar{} \emph{Is my paper ready to submit?} \textbar{} Module 1:
Manuscript Readiness Checker \textbar{} \textbar{} \emph{Which journals
fit my paper?} \textbar{} Module 2: Journal Discovery \& Matching
\textbar{} \textbar{} \emph{Are those journals trustworthy?} \textbar{}
Module 3: Journal Trust Scorer \textbar{} \textbar{} \emph{How does my
paper compare to its field?} \textbar{} Module 4: BI Dashboard \&
Benchmarking \textbar{}

\textbf{Core principles:} radical transparency, hybrid intelligence,
user‑centric design, security \& privacy by design, zero‑cost
infrastructure (no API keys, no usage limits, no vendor lock-in).

\subsubsection{3.2 End-to-End Hybrid Data
Flow}\label{end-to-end-hybrid-data-flow}

\begin{enumerate}
\def\labelenumi{\arabic{enumi}.}
\tightlist
\item
  \textbf{Upload:} PDF/DOCX uploaded → extracted via \texttt{pdfplumber}
  / stored in MinIO.
\item
  \textbf{Symbolic Phase:} Run structure, acronyms, citation‑reference,
  and grammar (LanguageTool) checks.
\item
  \textbf{Statistical NLP:} Readability, passive voice, lexical
  diversity, jargon extraction (textstat, spaCy).
\item
  \textbf{Semantic Phase:} Embed abstract, extract keywords (KeyBERT),
  compute topic similarity.
\item
  \textbf{Agent Orchestration (LLM):} Parallel Celery agents execute
  specific analysis tasks using Ollama.
\item
  \textbf{Async Enrichment:} Resolve references via Crossref, fetch
  citation data from OpenAlex, build citation graph.
\item
  \textbf{Benchmarking:} Compare manuscript against field benchmarks
  (precomputed nightly).
\item
  \textbf{Convergence:} Aggregate all results into JSON payload with
  provenance IDs and stream to frontend via SSE.
\end{enumerate}

\subsubsection{4.2 Agent Orchestration (Celery +
Redis)}\label{agent-orchestration-celery-redis}

11 separate LLM calls cause high latency. We optimize this using a
\textbf{Celery Chord} (parallel groups + sequential callback): -
\textbf{Phase 1 (I/O):} Extract PDF, chunk, and embed. - \textbf{Phase 2
(Parallel LLM - 6 concurrent calls):} - \emph{Group A:} Document
Intelligence (title, authors, keywords) - \emph{Group B:} Language \&
Compliance (grammar, citations) - \emph{Group C:} Originality Analysis
(plagiarism risk, novelty) - \emph{Group D:} Research Rigor (methodology
score) - \emph{Group E:} Submission Readiness (journal fit) -
\emph{Group F:} Peer Review Simulation (3 personas) - \textbf{Phase 3
(Dependent Chain):} Truth Checker → Quality Checker → Convergence.

\subsubsection{4.3 Caching \& Cost
Optimization}\label{caching-cost-optimization}

\begin{itemize}
\tightlist
\item
  \textbf{Content-Addressable Cache:} Hash the extracted text. If the
  same paper is uploaded, return cached results instantly (100\%
  savings).
\item
  \textbf{Embedding Cache:} Embeddings are deterministic. Cache them in
  Redis by chunk content hash (30\% savings).
\item
  \textbf{LLM Response Cache:} Cache deterministic prompts (like
  metadata extraction) in Redis (15\% savings).
\end{itemize}

\begin{itemize}
\tightlist
\item
  \textbf{Data Privacy:} On-premise processing. Vectors and LLM inputs
  never touch third-party APIs. MinIO buckets are private. Files deleted
  after 2h.
\item
  \textbf{Resilience:} Celery auto-requeues failed tasks. LLM calls
  wrapped in \texttt{tenacity} for exponential backoff retries.
\item
  \textbf{Input Sanitization:} 50MB max file size. PDF sandboxing
  (extracted in network-isolated containers).
\item
  \textbf{Observability:} Prometheus tracks metrics (tokens consumed,
  task latency). Loki aggregates JSON logs. Jaeger provides distributed
  tracing (e.g.,
  \texttt{{[}Upload{]}\ →\ {[}Extract{]}\ →\ {[}Embed{]}\ →\ {[}Group\ A{]}}).
\end{itemize}
